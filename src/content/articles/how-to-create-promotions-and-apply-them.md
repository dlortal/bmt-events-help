The Events system enables Admins to create a variety of Promotions that Users can utilise to discount their tickets.

Promotions can be applied to specific users, to specific event/s or to anyone with the promotion attached to their account. Admins are able to set a validity window between two dates, and other parameters such as the amount of uses per code.

## How to Create and View Promotions

Organisations can create a variety of promotions to run across Events or Users.

1.  Select **Promotions** from the left-hand navigation.
2.  Select the **Add** button from the right hand side, or below the table.
3.  **Input** the following details to set the Promotion parameters:

**Internal Name** - input a Promotion name to be viewed internally by Admins. This can help distinguish between multiple Promotions.

**Name** - input a Promotion name to be viewed externally by Users on the Booker Interface.

**Redirect URL** - the User will be taken to this page after applying the code to their account. If this is left blank then the User will be taken to the event listing page, or the event details page if applied to a specific event.

**Description** - input a description of the Promotion. This will be shown to Users when the code is validated.

**Terms & Conditions** \- input any T&Cs relating to the Promotion. Ensure to format the T&Cs accordingly using the WYSIWYG editor.

**Valid From** - select the date and time the Promotion is valid from.

**Valid Until** - select the date and time the Promotion is valid until.

5.  **Select** who the promotion **Applies To** from the drop-down options. Please note, more or less steps will appear dependent upon the answer.

**Anyone with promotion attached to their account** *-* selecting this option will provide a button to generate a series of codes. These can then be emailed or distributed out to Users, who should then add this discount to their account.

**Everyone who books event** *-* selecting this option will apply the discount to any associated events. Promotions can be applied to specific events during the event creation or edit process.

**Specific Users** *-* selecting this option will only apply the discount to specific Users.

6.  **Select** the **Scope** of the promotion from the drop-down options:

**Per-booking Only** - select this option for the Promotion to only apply to individual Bookings to a singular Event.

**Cross-booking Only** - select this option for the Promotion to only apply when a User checks out and completes a basket with two or Bookings.

**Any** - select this option for the Promotion to apply to either of the above scenarios.

7.  Continue to **input** the promotion parameters:

**How Many Codes to Generate** - input the number of codes to generate. This is key to the type of promotion created e.g. 1 code (10%OFF) could be set to be used 50x, or alternatively create 50 unique codes with one use. Note this number can only be increased, not reduced.

**Users Per Code** - input the number of uses per code. This determines how many times a single code can be used to enable a promotion on a user's account.

**Uses Per User** - input the number of uses per user. This determines how many times a user can use the promotion once it is attached to their account.

**Total Uses (Across All Users)** - input the total number of uses across all users. This determines how many times the promotion can be used by all the users who have it attached to their account.

**Apply Multiple Times in the Same Basket** - select from the drop-down list if the code can be applied multiple times in the same basket.

8\. **Select** the appropriate options from the drop-down lists and input the following details to outline the Promotion:

Buying: “\_\_A\_\_” or more “\_\_B\_\_” ticket\[s\]

Gets: The cheapest “\_\_C\_\_” “\_\_D\_\_” ticket\[s\] at “\_\_E\_\_” “\_\_F\_\_” off

A - how many tickets must be bought to activate the promotion.

B - select the specific ticket type if applicable, or leave as ‘Any Type’ to apply to all ticket types.

C - select how many tickets to apply the promotion to.

D - select the specific ticket type if applicable, or leave as ‘Any Type’ to apply to all ticket types.

E - input a numerical value with correct decimal places, depending on F.

F - select for the promotion to be applied via currency or percentage of ticket price.

9\. **Review**, and ensure to **Save & Close**.

10.  If the ‘Everyone Who Books Event’ option was selected, ensure to **select the Promotion** when building or editing the respective Event.

Once the Promotion has been created, it will be displayed on the Promotion List page. From here, the following can also be actioned -

-   **Download** - will download a CSV of the Promotion table data.
-   **Filter By** - input text into the Promotion Name, No. Uses per User or No. Uses columns to search the table.
-   **Clear Filters** - will clear any filters as applied above.

## How to Edit and Delete Promotions

Promotions may need to be edited or even deleted from the site. To edit an existing Promotion, follow these steps -

1.  Select Promotions from the left-hand navigation.
2.  Select **Edit** from menu, on the respective promotion.
3.  **Update** the relevant fields.
4.  **Review**, and ensure to **Save & Close**.

If a Promotion is no longer relevant or required, following the above steps but select **Delete** from the drop-down menu. Admins will need to confirm the deletion by typing ‘I Am Sure', to permanently remove the Promotion from the Admin site - the Promotion cannot be retrieved once deleted.

The BAFTA Events platform allows Admins to populate ticketholder details in bulk for existing bookings. This helps save time and reduces the risk of manual entry errors when assigning names and email addresses to multiple tickets.

Using the **Populate Guest Names** function, Admins can upload a list of guest details which will automatically be applied to tickets within a booking.

### Preparing your guest list

Guest details must be entered in the following format:

-   One guest per line
-   Details separated by commas
-   Order: **First name Last name, Email address**

Example:  
`Jane Smith, jane.smith@email.com`

Ticketholder details are assigned from top to bottom and are only applied to tickets where the fields are currently empty.

### How to batch upload ticketholder names

Log in to the Admin side of BAFTA Events.

1.  Navigate to either the **Events List** page.
2.  Locate the relevant booking.
3.  From the Actions drop-down on the right-hand side, select **Details**.
4.  You will be taken to the booking details page.
5.  Scroll to the bottom of the page and select **Populate Guest Names**.
6.  Paste the guest information into the text area provided.
7.  Select **Save** or **Save and Close** to apply the changes.

### Validation and system behaviour

Before changes are applied, the system validates the information provided and will flag any issues that require attention. This includes:

-   More guest entries than available tickets
-   Missing or invalid email addresses
-   Duplicate email addresses
-   Incomplete first or last names
-   Email addresses that already exist on another ticket
-   Fields that have already been populated and cannot be overwritten

Where applicable, the system will clearly indicate what has been updated, what has been skipped, and why. A summary is shown so Admins can review the outcome and amend the guest list if needed before confirming.

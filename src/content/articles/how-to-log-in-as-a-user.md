Occasionally Admins may need to log in as a specific User to assist with troubleshooting, take an action on their behalf or simply just review how the User Interface looks for different User Types.

The BAFTA Events platform enables Admins to log in as any end User and complete actions through their account, such as requesting tickets or managing bookings.

It can be advisable for Admins to create their own public accounts on the system (per applicable User Type) to assist with testing.

### How to Log In as a User

1.  **Log in** to the Admin side of BAFTA Events.
2.  Select **Users** from the left-hand navigation.
3.  Use the **column filters** to find the respective User.
4.  Select the three-dot menu (…) at the far right of the user’s row.
5.  Select **Login As** from the drop-down menu. This will open a new tab to the User Interface, logged in as the User.

**Note** - Be mindful when taking any actions that may trigger notifications to the User, such as signing up to a Waitlist or booking into an Event.

7.  Ensure to **log out** after completing.

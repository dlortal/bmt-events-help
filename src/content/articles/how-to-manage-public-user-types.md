Public User Types can either be manually created by Admins, or synced with a Customer Relationship Management (CRM) platform depending on site setup. They are used throughout the structure of the BAFTA Events platform to determine which events a user can at access or privileges a User may have.

For instance, when building an event Admins can determine what User Types can view it or if they can proceed to booking. This assists with the creation of ‘private’ or non public-facing events, and is particularly helpful for membership based organisations.

Notably, when completing Site Setup Admins will be required to select which User Type people will automatically be assigned when they autonomously create an account via the Booker Interface sign up page. This is done on a per Branch basis in the Branch settings.

## How to Add and View User Types

1.  **Log in** to the Admin side of BAFTA Events.
2.  Select Users from the left-hand navigation, then select Public User Types.
3.  Select **User Types** from the menu.
4.  Select the **Add** button from above or below the table.
5.  **Input** the following details:

-   **Public Name** - the User Type name as shown to end-users on their account.
-   **Internal Name** - the User Type name shown internally to Admins.
-   **Allowed to Cancel Tickets** - select Yes or No to determine if this User Type can cancel tickets to Events.

6.  **Review**, and ensure to **Save & Close**.

**Note** \- User Types are defined on a per Branch basis.

## How to Edit and Delete User Types

1.  Select Users from the left-hand navigation, then select Public User Types.
2.  Select **User Types** from the menu.
3.  Navigate to the **Actions** menu on the left hand side of the table.
4.  Select **Edit** from the drop-down menu of the respective User Type.
5.  **Update** the relevant fields.
6.  **Review**, and ensure to **Save & Close**.

**Note** \- to bulk change a group of User’s User Types, please refer to this guide.

If a User Type is no longer relevant or required, follow the above steps but select **Delete** from the drop-down menu. Admins will need to confirm the deletion by typing ‘I Am Sure', to permanently remove the User Type from the Admin site and Booker Interface - the User Type cannot be retrieved once deleted.

Please be mindful of how this may affect past Events or data when actioning the above.

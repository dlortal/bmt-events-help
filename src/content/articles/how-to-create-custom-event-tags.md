Admins can create custom Event Tags and label events accordingly. These will appear on the Events List page in a yellow box above the respective Event’s title.

This can assist with signposting to Users the nature of the Event, or important information. For example, Admins could tag with the Event’s category such as ‘Film’ or note that ‘BSL’ will be available.

This functionality can be utilised to best suit an organisation’s needs or aims.

### Step One: Create the Tags

1.  **Log in** to the Events Admin interface. 
2.  Select **Control Centre** from the header tabs. 
3.  Select **Branches** from the menu. 
4.  Navigate to the respective **Branch** and select **Edit** from the **Actions** menu. 
5.  Navigate down the page to the **Display** section. 
6.  Select the **Add** button and input the new **Event Tag / Type name** e.g. Conference. 
7.  Make sure to **Save** the tag on the right hand side. 

### Step Two: Label Specific Events

1.  Select **Events** **List** from the left-hand menu tabs. 
2.  Navigate to the respective **Event** and select **Edit** from the **Actions** menu. 
3.  In the **Basic Details** section, navigate to the **Type** section. 
4.  Select which **Tags** to **label** the event with. 
5.  **Review**, and **Save & Close**.
6.  **Log in** as a User to view the Event and respective tags. 

**Note** \- Tags can be added during the building of a new Event, as well as when editing a pre-existing one.

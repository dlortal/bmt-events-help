You can choose to display certain events to users who are not signed in. This is useful when the event is open to the general public and you want to increase visibility without requiring users to log in or create an account.

### To do this:

1.  **Log in** to the Admin side of BAFTA Events.
2.  Select **Events List** from left hand tabs menu.
3.  Find the event you'd like to update and click the **Action** button on the right-hand side.
4.  Select **Edit** from the dropdown menu.
5.  Scroll down to the **Event Visibility and Booking Rules** section.

### You’ll need to check two things:

#### 1\. Event Visibility

Ensure **Event Visibility** is set to **All Users**.  
This means the event can appear in public-facing listings for users who aren’t signed in.

#### 2\. Booking Rules

There must be at least one **Ticket Rule** for the **(General) Public** user type.  
For example, a ticket type like **Anyone** should be included here to ensure the event is accessible.

An event will only appear to logged-out users if at least one of the above conditions is met. Ideally, both should be in place to allow for both visibility and access.

### What logged-out users will see

Once the event has been saved with the correct settings, it will appear in the public “What’s On” listings and on any other relevant pages where events are surfaced.

Logged-out users will be able to:

-   View the event details
-   Book tickets (if available to the General Public)
-   Share or return to the event without needing to create an account

### Things to note

-   Events marked as **Members only** or with no public ticketing option will remain hidden to users who are not signed in.
-   Visibility changes take effect as soon as the event is saved.
-   This feature applies to all event types, including screenings, livestreams, and in-person events.

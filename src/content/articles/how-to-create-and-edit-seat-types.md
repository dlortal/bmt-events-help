The Events platform enables Admins to create different ‘Seat Types’ and input details that represent the physical seats or spaces in Auditoriums and Venues.

‘Seat Types’ are linked to other features within the site, including but not limited to Auditoria, Venues and Seat Plans. For instance, Seat Types must be associated with a Venue and are used to build Seat Plans for allocated seating based Auditoria.

Users will engage with Seat Types on the Booker Interface when booking tickets for an event with allocated seating. Admins can opt from a range of seat icons and name their seats accordingly to inform Users what they can expect from a seat.

### How to Create Seat Types

Before Seat Types can be utilised within Seat Plans, they must first be created. Follow these steps -

1.  Select Venue Management from the left-hand navigation, then select Seat Types.
2.  Select **Seat Types**.
3.  Select the **Add** button from the right hand side, or below the table.
4.  **Input** the following details:

-   **Venue** - select which Venue to place the Seat Type at.
-   **Name** - input a name for the Seat Type i.e. Accessible or Plush.
-   **Description** - write a description of the Seat Type.
-   **Icon** - select an appropriate icon from the drop-down list. From here you can also create Accessibility seats. Please follow [this guide](/help-articles/accessibility-features-setup-and-management/) for the full Accessibility seats workflow.
-   **Seat Colour** - select a colour for the Seat Type from the colour picker.

5\. Click on **Save & Close** when done.

Once the Seat Type has been created, it will be displayed on the Seat Type List page. From here, the following can also be actioned

-   **Download** - will download a CSV of the Seat Type table data, including Name, Icon and Venue Name.
-   **Filter By** - input text into the Seat Type columns or select from the Venue Name drop-down to search the table.
-   **Clear Filters** - will clear any filters as applied above.

### How to Edit and Delete Seat Types

Seat Types may been to updated or even deleted over time. To edit an existing Seat Type, follow these steps -

1.  Select Venue Management from the left-hand navigation, then select Seat Types.
2.  Select **Seat Types**.
3.  Navigate to the **Actions Menu** on the left hand side of the table.
4.  Select **Edit** from the drop-down menu.
5.  **Update** the relevant fields.
6.  **Review** and ensure to **Save & Close**.

If a Seat Type is no longer relevant or required, follow the above steps but select **Delete** from the drop-down menu. Admins will need to confirm the deletion by typing **I Am Sure**, to permanently remove the Seat Type from the Admin site and Booker Interface - the Seat Type cannot be retrieved once deleted.

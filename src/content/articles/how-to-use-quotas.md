When building Events, Admins are able to put Ticket Type quotas in place that will delineate the composition of the audience.

This works in conjunction with the Ticket Matrix. The Ticket Matrix determines how many tickets of what ticket type an *individual user* can book, and Quotas determine what number of each ticket type can be booked overall across the event. For example, Members can book up to two Standard tickets each and overall Admins would like Standard tickets to make up 40% of the audience.

Admins can opt to either set a cap on the maximum number of a specific ticket type booked, or similarly to reserve a specific amount of a ticket type. Through various set ups, Admins can achieve a variety of compositions for their events.

## How to Add a Quota

1.  **Log in** to the Admin side of BAFTA Events.
2.  Select **Events** from the left-hand side menu.
3.  **Navigate** to the desired Event
4.  To open it, either **click on its name**, or click on the **...** Actions menu on its right-hand side and select **Edit**
5.  Once the Event page is open, click on the **Quotas** tab at the top of the page
6.  Select the **New Quota** button.
7.  **Input** a **Name** for the quota (this is optional).
8.  **Decide** which **Quota Type** to use:
    -   **Max No. Tickets per Ticket Type** - asks Admins to input the max number of tickets that can be sold for a specific Ticket Type.
    -   **Reserve No. per Ticket Type** - asks Admins to input a number of tickets to reserve for a specific Ticket Type.
    -   **Max % Tickets per Ticket Type** - asks Admins to input a percentage of total event capacity that can be allocated to a specific Ticket Type.
    -   **Reserve % Tickets per Ticket Type** - asks Admins to input a percentage of total event capacity to reserve for a specific Ticket Type.

**Tip** \- Multiple quotas can be created for one Event to curate a specific audience composition. Think about which rule or combination of rules would best suit.

**Tip** - As part of the updated and safer quota set-up, Admins will only see Ticket Types that are currently bookable for the Event when creating or editing quotas.

9.  Input a **Limit** number that determines how many tickets the Quota is valid for.
10.  Choose **Ticket Type**.
11.  Select a **Seat Type** from the drop-list (this is optional).
12.  Input a **date and time** that the quota will apply til (this is optional - if left empty, it will be in effect for the whole booking window).
13.  Ensure to select the **Save button** to complete the quota. This quota will come into effect as soon as it is saved or the event opens for booking.

**Tip** \- Admins can utilise the date and time settings to create tiered or staggered ticket releases.

**Note** \- Different Event Statuses such as Sold Out, Limited & Low Availability or Waitlist are impacted by the quotas put in place.

14.  To delete a quota, click on the **X** on the right hand side of the respective quota.

## How to Review a Quota’s Status

To review a quota’s status, begin by following steps 1-5 above to arrive at the respective Event’s quota page.

1.  **Navigate** down the page to the Tickets Sold section.
2.  **Review** the number of tickets sold in each Ticket Type quota, against the maximum amount; including the total overall sold and remaining tickets left.
3.  **Navigate** further down to the **Quota Detail** table, for a more granular breakdown, including Quota Type and tickets remaining.

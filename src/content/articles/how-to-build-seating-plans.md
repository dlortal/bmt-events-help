In order to create a seating plan within the BAFTA Events platform, your event must be linked to an **auditorium** with **allocated seating** enabled. Below is a step-by-step guide on how to set this up, from creating the auditorium to building the plan itself.

**1\. Create a New Auditorium with Allocated Seating**

To enable seating plans, allocated seating must be set at the **auditorium level**. This cannot be changed once saved, so accuracy is essential.

## Steps:

1.  Log into the **Admin** side of the Events platform.
2.  From the top navigation bar, click **Venues**.
3.  In the dropdown, select **Auditoria**.
4.  On the Auditoria page, click the **Add** button (either at the bottom of the list or in the top-right corner).

**Note**: Once an auditorium is saved with or without allocated seating, this setting cannot be edited. If it’s incorrect, delete the auditorium and create a new one.

## Basic Details:

-   Before doing all of this you’ll need to [create a Venue](/help-articles/how-to-create-and-edit-venues/) and [Seat Types](/help-articles/how-to-create-and-edit-seat-types/) first
-   Select the correct **Venue** from the dropdown.
-   Choose **Allocated seating? > Yes** from the dropdown.
-   Complete all necessary fields, including:
    -   **Total capacity**
    -   **Seat plan** (optional at this stage – JPG, PNG, or GIF format)
    -   **Auditorium Information** (description below the seat map)
    -   Remember to complete other relevant sections such as **Accessibility** and **Terms and Conditions** with the appropriate information for your event.
-   You may also create **seat types** by following this [guide](/help-articles/how-to-create-and-edit-seat-types/).
-   Click **Save** to complete the process.

## 2\. Apply Auditorium to an Event

Once your auditorium is created, you can link it to your event.

## Steps:

1.  Return to the **Events** list from the admin navigation.
2.  Find the event you are working on.
3.  Click the **Actions** menu (right-hand side of the row).
4.  Select **Edit** from the dropdown.

This will take you to the **event information page**. Make sure the correct **auditorium** is applied under the "Auditorium" field.

## 3\. Access the Seat Plan Builder

From the event’s edit page:

1.  Look for the set of tabs in the upper-right:  
    **Pending Bookings | Attendance | Seat Plan | Bookings**.
2.  Click on **Seat Plan**.

This opens the **Seat Plan Builder**, where you can:

-   Manually build the seat layout.
-   Apply seat types, prices, and colour-coding.
-   Assign specific blocks or areas of seating.

In some cases, a seating plan may be provided by a client or already exist from a previous event.

## Summary & Key Reminders

-   **Allocated seating must be enabled** at auditorium creation to use a seating plan.
-   Auditoriums **cannot be edited** to change seating allocation once created.
-   Always ensure the correct auditorium is applied before building the seat plan.
-   Use the **Seat Plan** tab in the event editor to configure the layout, pricing, and capacity.

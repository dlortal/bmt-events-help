This guide explains how admins can include file attachments when sending emails from BAFTA Events using **Bulk Mailouts** and **Contact Emails**.

This feature allows supporting documents (such as PDFs, Word files or schedules) to be sent directly from the platform, reducing the need to use external email systems and keeping event communication in one place.

### What this feature allows you to do

Admins can:

-   Upload a file while composing a Bulk Mailout or Contact Email
-   Send that file as an attachment to all recipients of the email
-   Keep communication linked to the relevant event inside BAFTA Events

Attachments are used only for the email being sent and are not stored long-term in the system.

### Supported files and limits

To ensure performance and email deliverability, attachments must meet the following rules:

-   **Maximum file size:** 5MB
-   **Supported file types:**  
    pdf, doc, docx, xls, xlsx, ppt, pptx, txt, rtf, jpg, jpeg, png, zip

Files that exceed the size limit or are not in an allowed format cannot be uploaded.

Attachments must be uploaded again for future emails — previously used files are not saved for reuse.

### Add an attachment to a Bulk Mailout

### Path (Admin)

1.  Log in to the admin interface.
2.  Go to Events List and locate the relevant event.
3.  Via the Actions menu dropdown open the **Bulk Email** tool.
4.  Compose your email as usual.

Below the **Email body text** field, you will see the option to upload an attachment.

5.  Select the upload option.
6.  Choose a file from your computer.
7.  Confirm the file appears as attached.
8.  Complete the rest of the email setup.
9.  Preview to make sure the email is correct and ready for sending.
10.  Click on **Next**.
11.  **Send** when ready.

The selected file will be attached to the email received by all recipients.

### Add an attachment to a Contact Email

Contact Emails allow admins to message an individual booking or contact.

### Path (Admin)

1.  Log in to the admin interface.
2.  Go to the Events List page > Find your event.
3.  Open the actions menu on the left > from the dropdown select ‘**Contact**’.
4.  You’ll be taken to a page titled ‘**Totals after deduplication**’
5.  Confirm this information is correct and click on the **Next** button below.
6.  You will be taken to the ‘**Specify Email Details**’ page.
7.  Fill out all of the relevant information.

Below the Email body text section, you will see the option to upload an attachment.

5.  Select the **upload** option.
6.  Choose a file from your computer.
7.  Confirm the file appears as attached.
8.  You have the option to **Preview** the email before sending.
9.  **Send** the email when ready.

The file will be attached to the email received by the contact.

Every event has a guest list. Guests on the list can be invited, ticketed and checked in.

## Add one guest

1. Open the event and choose **Guests**.
2. Select **Add guest** and enter their name and email address.
3. Choose a ticket type and select **Save**.

## Upload a list

1. Download the template from **Guests**, then **Upload**.
2. Fill in one guest per row. Keep the column headings unchanged.
3. Upload the file. Rows with problems are listed so you can fix them before anything is added.

| Column | Required |
| --- | --- |
| First name, last name | Yes |
| Email | Yes |
| Ticket type | Yes |
| Dietary requirements | Optional |

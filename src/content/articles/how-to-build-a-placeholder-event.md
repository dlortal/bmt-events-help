Not all Events require bookings and/or tickets to take place. Sometimes Admins may wish to simply just signpost to Users that an Event is happening and not require any further actions. Examples of this include networking sessions, coffee mornings or reception drinks.

The Events platform enables Admins to populate an Event with all the relevant information - such as image, description, date, time, venue, auditoria, accessibility information and Google maps link - but remove the Call to Action button.

1.  **Login** to the **Admin interface** of Events.
2.  Select **Events List** from the left-hand tabs.
3.  Select the **Add button** in the top right hand corner.
4.  Select **No** for the **‘Event is a Parent’** input, unless following this [guide](/help-articles/how-to-create-a-parent-child-event-setup/).
5.  Select **‘Placeholder Only’** from the drop-down list, under Sales Platform.
6.  Follow the remaining **relevant steps** in this [guide](/help-articles/how-to-create-a-standard-event/) to finish building the Event.
7.  It is advisable to [login as a test User](/help-articles/how-to-log-in-as-a-user/) to ensure the Event is appearing as expected.

**Note** \- if Admins want only specific User Types to have access to this Event, they will need to create this as a standard Event first (Sales Platform: Events Ticketing) to access the Ticket Matrix, save and then change back to a Placeholder Only.

**Tip** \- ensure the Event copy reflects that no booking is required to attend.

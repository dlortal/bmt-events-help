**Preview Mode** allows you to view how an event page will appear to bookers before it goes live. This is useful for checking content, layout and presentation before publishing.

### When to use it

Preview Mode is helpful when you want to:

-   Check titles, descriptions and images
-   Review pricing and ticket information
-   See how the overall page will look to bookers

This can help reduce errors and avoid publishing incomplete or incorrect event pages.

### How it works

Preview Mode is available for events that are set to **Pending** status (see below for more on the new Pending status). Pending status [guide](/help-articles/understanding-the-new-pending-event-status/).

## How to Use the Preview Mode

1.  Log in to the admin side of BAFTA Events
2.  Select **Events** **List** from the tabs menu
3.  Scroll down to find the event you want to preview and click to open it
4.  In the **Status** dropdown, select **Pending** (if not already selected)
5.  Click **Save** to update the status
6.  Click the **Preview** button in the event toolbar – this will appear in the top right-hand corner of the screen alongside the other event action buttons

The event will open in a new tab, showing exactly how it will appear to bookers.

**Note -** Only admin users can use Preview Mode. Events in Pending status are not visible on the public events list. A “Preview User” is created automatically per admin the first time they’re created.

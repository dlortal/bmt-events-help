Whilst most Events will be booked via the Events platform, there may be occasions where Admins wish to link out to an external platform. Admins have the ability to add in a URL, which Users will be redirected to when selecting the usual Book Tickets button.

This enables Organisations to collaborate with external partners, or host online Events on platforms such as Zoom.

1.  **Login** to the **Admin interface** of Events.
2.  Select **Events List** from the left hand menu tabs.
3.  Select the **Add button** in the top right hand corner.
4.  Select **No** for the ‘Event is a Parent’ input, unless following this [guide](/help-articles/how-to-create-a-parent-child-event-setup/).
5.  Select **‘External Website’** from the drop-down list, under **Sales Platform**.
6.  This will produce an additional drop down named **‘External Booking URL’**, where a **URL** can be added.
7.  Input a link in the drop-down where the end User will be **redirected** to when selecting the Book Tickets button.
8.  Follow the remaining **relevant steps** in this [guide](/help-articles/how-to-create-a-standard-event/) to finish building the Event.
9.  It is advisable to [login as a test User](/help-articles/how-to-log-in-as-a-user/) to ensure the Event is redirecting correctly.

**Note** \- if Admins want only specific User Types to have access to this Event, they will need to create this as a [standard Event](/help-articles/how-to-create-a-standard-event/) first (Sales Platform: Events Ticketing) to access the Ticket Matrix, save and then change back to a External Website.

**Note** \- where the booking process is taking place outside the system, no statistics can be collected on how many tickets have been sold.

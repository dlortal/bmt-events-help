A new **Pending** status has been introduced in the admin events system to support better event setup and staging. Events marked as Pending are not visible to the public, but can be previewed in full by admin users.

## When to use it

Setting an event to **Pending** allows you to:

-   Prepare an event without it appearing publicly
-   Use **[Preview Mode](/help-articles/how-to-use-preview-mode-for-events/)** to check how the event will look to bookers
-   Reduce the need to create separate test events

This is particularly useful when you want to stage an event in advance, and ensure it’s fully reviewed before going live.

## How to use it

To mark an event as Pending:

1.  Log in to the admin side of BAFTA Events
2.  Select **Events** **List** from the tabs menu
3.  Scroll down to find the event you want to update and click Action button and select edit to open it
4.  In the Basic details section locate the **Status** dropdown, select **Pending**
5.  Click **Save** to confirm your changes

The event will now be hidden from the public-facing events list, but admin users will still be able to access it and use **Preview Mode**.

> **Note:** Preview Mode is only available for events that are set to Pending. Learn how to use Preview Mode.

## Setting a “Display on Events List” date

You can now set a **Display on Events List** date to control when a Pending event appears publicly.

This is helpful if you want to:

-   Schedule an event to go live on a future date
-   Avoid having to manually update the event at the time of publishing
-   Stage content in advance while keeping it hidden from bookers

To set this:

1.  Scroll to the **Display on Events List** field (located in the event details section)
2.  Choose the date and time you’d like the event to become visible
3.  Save your changes

The event will automatically appear on the public events list at the specified time, even if it remains in Pending status.

Once you're ready for the event to go live immediately, you can manually change the status to **Live**.

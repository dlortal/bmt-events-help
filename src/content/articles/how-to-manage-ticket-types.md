Admins can create custom Ticket Types within the Events system and determine what ‘ticket allocation’ each applicable User Type can have when building an event. For instance: Standard, VIP, Premium, Public Concessions, Industry and more.

Offering multiple ticket types enables Admins to provide benefits to different Users, such as individual pricing or displaying relative ticket definitions on a per Branch or organisation basis.

‘Ticket Types’ will be linked to other features in the site, such as quotas and promotions. For instance, Admins can put ‘ticket quotas’ in place to curate the composition of their audience, or offer specific discounts when certain ticket amounts are purchased.

A minimum of one ticket type must be created for bookers to reserve tickets to an event.

## How to Add and View Ticket Types

It is advisable during site setup to create initial or baseline Ticket Types, after which additional types can be added throughout continued use of the site and expansion of events.

1.  **Log in** to the Admin side of BAFTA Events.
2.  Select Venue Management from the right-hand navigation, then find Ticket Types.
3.  Select **Ticket Types** from the menu.
4.  **Ensure** the correct Branch is filtered from the top of the page.
5.  Select the **Add** button from above or below the table.
6.  **Input** the following details:

**Internal Name** - the Ticket Type name to be viewed internally by Admins. This can help distinguish between multiple ticket types.

**Public Name** - the Ticket Type name to viewed publicly by end-users of the site.

**Description** - a description of the Ticket Type being defined.

5.  **Review** and **Save & Close**.

## How to Edit and Delete Ticket Types

1.  Select Venue Management from the left-hand navigation, then select Ticket Types.
2.  Select **Ticket Types** from the drop-down menu.
3.  Navigate to the **Actions** menu on the right hand side of the table.
4.  Select **Edit** from the drop-down menu of the respective Ticket Type.
5.  **Update** the relevant fields.
6.  **Review**, and ensure to **Save & Close**.

If a Ticket Type is no longer relevant or required, follow the above steps but select **‘Delete’** from the drop-down menu. Admins will need to confirm the deletion by typing ‘I Am Sure', to permanently remove the Ticket Type from the Admin site and Booker Interface - the Ticket cannot be retrieved once deleted.

Please be mindful of how this may affect past Events or data when actioning the above.

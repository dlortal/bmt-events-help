Older events are now automatically moved to a separate **Archived Events** list to help keep your main Events List clear and focused on current and upcoming activity.

This guide explains where to find the Archived Events page and how archived events behave.  
  
**When are events archived?**

Events are moved to the archive 60 days after their end date (this is the default system setting). Once archived, the event is removed from the main Events List view but is still fully accessible.  
  
**How to access the Archived Events page**

1.  **Log in** to the **Admin side** of BAFTA Events.
2.  Select **Events List** from the menu tabs to the left.
3.  Click the **Archived Events** button at the top right of the page, above the events table.
4.  This will open a list showing all archived events.
5.  To return to Live events click on the **Current Events** button at the top right of the page.

Archived events use the same table layout as the main Events List, so you can sort, filter and view them in the same way.

### Can I move an event back to the main list?

Yes. If you need to make an archived event visible in the main Events List again, simply **update the event’s end date** to a date within the last 60 days. The event will automatically reappear in the main list.

### Are archive actions tracked?

Yes – any movement of events in or out of the archive is recorded in the **Action Log** for full transparency.

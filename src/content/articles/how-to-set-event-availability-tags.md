Events can sell out quickly on the BAFTA Events platform and it can be useful to signpost how many tickets are still available to end Users.

Admins have the option of surfacing the Availability Status of an Event on the homepage and Event Detail page. This will appear to Users as a tag on the Event image, stating information such as Low Availability or Limited Availability.

The functionality is primarily set at the Branch level, but can be overridden on a per Event basis if specific parameters are required.

## Step One: Set at Branch Level

1.  **Log in** to the Events Admin interface. 
2.  Select **Control Centre** from the left-hand tabs menu. 
3.  Select **Branches** from the page menu. 
4.  Navigate to the respective **Branch** and select **Edit** from the **Actions** menu. 
5.  Navigate towards the bottom of the **Basic Details** section. 
6.  Select **Yes** on the **Display Low/Limited Availability** **Tags** drop-down. 
7.  Input the **percentage** an event should be sold out to flag as ‘Low Availability’. 
8.  Input the **percentage** an event should be sold out to flag as ‘Limited Availability’. 
9.  **Review**, and **Save & Close**. 

## Step Two: Set at Event Level

1.  Select **Events List** from the left-hand tabs menu. 
2.  Navigate to the respective **Event** and select **Edit** from the **Actions** menu on the right hand side.  
3.  Navigate to the bottom of the **Basic Details** section. 
4.  Select **Yes** or **Default** on the Event Status drop-down. Default will match the Branch settings - select Yes to set Event specific parameters that will override the default.
5.  Input **percentage** the event should be sold out to flag as ‘Low Availability’. 
6.  Input **percentage** the event should be sold out to flag as ‘Limited Availability’. 
7.  **Review**, and ensure to **Save &** **Close**. 

**Tip** - Use the Admin Booking functionality to mostly sell out the Event and test that the tags appear as expected.

The BAFTA Events platform provides Admins with the ability to curate a variety of different booking journeys, empowering the end Users to book and manage their tickets independently.

However, there may be occasions where Admins wish to book on behalf of guests or simply reserve seats/space in their event. For instance, booking in VIPs, staff or reserving ‘rush tickets’.

The ‘Admin Book’ functionality will override certain workflows such as the Request/Approve process and will price tickets as free. Once a User has been booked on behalf of, they will be able to manage the respective booking in their My Bookings tab.

### How to Admin Book Tickets

1.  **Log in** to the Admin side of BAFTA Events.
2.  Select **Events List** from the left-hand navigation, then find the relevant event.
3.  Select the three-dot menu **(…)** at the far right of the event row, then select **Admin Book.**
4.  **Check** the Event detail information is correct, including: Internal Name, External Name, Start Date/Time, Venue and Auditorium.
5.  **Complete** the following inputs:

**Which User?** \- Type the User’s name or email to book on their behalf. Please note, the User must exist in the BAFTA Events system to do so. Alternatively, leave blank or choose No User to make a plain Admin Booking. Please note that if No User are selected, the Booking ID will be 0.

**Send Email to User** - This option will be automatically ticked when a User is selected in the step above. Untick this setting to not send a Confirmation Email to the respective User.

**Optional Address for Confirmation Email** - This setting will only show when a plain Admin Booking is made i.e. no User is selected. Input an email address to send a confirmation email to, if desired.

**What Type of Ticket** - Select the respective Ticket Type to assign the Admin Booking to. Please note: only Ticket Types enabled in the specific Event will show; Admin Bookings override the Ticket Matrix, meaning Admins can assign Ticket Types to Users they may not technically have been given access to; and lastly, only one Ticket Type can be selected per Admin Booking.

**How Many** \- Select how many Tickets to book under this Admin Booking.

**Tip** \- All Admin Bookings are free and cannot be assigned any costing. Additionally, they usually override certain Booking Flows, such as the Request/Approve workflow or Invoicing.

**Note** \- Bookings and tickets cannot be retrospectively re/assigned to a new User once they have been made. Please take this into account when making plain Admin Bookings.

8.  Select the **Choose Seats button** to either Confirm the booking if it’s in a non-allocated auditorium, or to proceed to select the Booking’s seats if in an allocated-seating auditorium.
9.  **Select** the desired **seat/s** on the Seat Plan.  
      
    To select multiple seats, you now have **two** options:

1.  **Marquee Mode**
    -   Press **“m”** on your keyboard to enter marquee mode.
    -   You will see an outline around the plan indicating marquee mode is enabled.
    -   Click once to set the initial corner of the marquee.
    -   Move your mouse to control the marquee size.
    -   Click again to set the opposite corner.
    -   Any seats inside the marquee will be selected, and the Batch Edit form will appear in the right-hand column.
    -   Press **Esc** to exit marquee mode at any time.
2.  **Ctrl + Click**
    -   Hold **Ctrl** and click multiple seats to select them.
    -   Once more than one seat is selected, the Batch Edit form will appear in the right-hand column.

8.  Select the **Book Tickets button** to confirm the booking.
9.  It is advisable to **double check the booking** once it has been confirmed.

**Tip** \- Once a Booking has been made on behalf of a User, they will now be able to view and manage the booking from the My Bookings section of their account.

### Populating Ticketholder Details for Admin Bookings

For Admin Bookings that contain more than one ticket, Admins can populate Ticketholder details in bulk using the Populate Guest Names option.

This option appears on eligible bookings once they have been created. Admins can paste a list of guest details into a text field using the following format:

-   First name, last name, email
-   One guest per line

Names are assigned from top to bottom and are only applied to empty Ticketholder fields.

Before the details are saved, the system validates the information and will flag:

-   More guest names than available tickets
-   Missing or invalid email addresses
-   Duplicate entries
-   Incomplete names

A summary screen is displayed, allowing Admins to review the changes, address any warnings, and amend or remove entries before confirming.

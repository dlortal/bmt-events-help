Admins can generate reports from the Events system, enabling them to view performance data or group statistics.

1.  Select Reports from the left-hand navigation.
2.  **Select** which Report to generate:

**Audience Types Bookable Events** - generates a CSV showing which User Types can book what Event.

**Attendance Report** - generates a CSV showing Event attendance by User Type.

**Attendee Report** - generates a CSV showing Attendee Data across Events between a specific time period.

**Cash Payout Report** - generates a CSV showing transactions taken under cash basis.

**Invoice Payout Report** - generates a CSV showing transactions taken under Invoice basis.

**Invoice Posting Report** – generates a CSV showing all invoice transactions with clarified field names and layout, including company or booker details for each entry.

4\. Select which **Branch** to pull data for, if requested.

5\. Input the **date range** from which to pull data for.

6\. Review and Select the **applicable criteria** for the desired download. For example, User Types or Attendee Data.

7\. Select the **‘Generate Report’ button** to download a CSV of the above criteria.

8.  **Open** the download to view the data.

**Tip** - The above functionality offers Admins the ability to pull data from across Events and time periods. However, it’s important to note that most pages on the Admin side of BAFTA Events have a Download button, offering the ability to download the data from that respective page. This allows for more specific or individual Event based reporting.
